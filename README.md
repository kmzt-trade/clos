# CLOS

Human Sovereignty Runtime · 人类主权运行时

CLOS 探索 AI 系统中的人类授权、执行边界与可验证记录。本仓库作为公开项目入口；当前提供项目介绍与导航，不包含可部署运行时，也不代表已完成工程验收。

## 核心原则

- Capability ≠ Authority：能力不等于授权。
- Prediction ≠ Permission：预测不等于许可。
- Decision ≠ Execution Right：决策不等于执行权。
- 人类保留最终授权与撤回权。

## 关注的运行流程

意图与上下文 → 授权检查 → 规范动作（Canonical Action）→ 执行 → 现实回执（Reality Receipt）→ 审计账本（Ledger）。

上述流程是项目研究方向，不构成本仓库实现状态的声明。
